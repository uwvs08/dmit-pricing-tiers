## The Three-Layer Pricing Model: Same Hardware, Different Routing

Here's the thing that confuses a lot of newcomers: DMIT doesn't sell "a VPS." They sell the *same* VPS three different ways, and the price swings based on which network profile you pick. Pick the wrong one for your use case and you either overspend or underperform.

- **Premium Network (Pro)** — Tier 1 transit plus premium partners including DMIT's own backbone and China Telecom CN2 GIA. Lowest latency, fewest hops, best routing to mainland China and Asia-Pacific. This is the "money is no object, I want it to actually work" tier.
- **Eyeball Network (EB)** — Tier 1 transit with "reasonable effort" China routing via CMIN2 / CMI and similar Chinese ISPs. A middle ground. You give up guaranteed premium routing for a friendlier price tag.
- **Tier 1 Network (T1)** — Standard international routing optimized for latency between regions, *without* China-specific optimization. The cheapest of the three, and honestly the right choice if your users aren't in China.

Same CPU, same RAM, same SSD — the only thing that changes between tiers is the network path your packets take. That's the whole game.

## Refund Policy: Short Window, Read The Fine Print

A lot of DMIT pricing discussions skip this, but it matters because it changes your real cost risk. DMIT offers full refunds (minus payment gateway fees) within the first 3 days of service, capped at 30GB of transfer used. Partial refunds are available within 30 days, calculated either on remaining time or remaining transfer — whichever is lower.

The exceptions are sharp: no refund if you've been hit by a DDoS attack, no refund if the network "isn't good enough" in your region, no refund once you've had three refunds on the same product series, and no refund if the IP isn't reachable in some countries but you've already used more than 3GB of transfer. The IP-reachability clause is the one that bites people who buy Premium for China access and then discover the IP is blocked — you need to flag it the same day you purchase.

So the practical takeaway: if you're testing the waters, start with the smallest plan in your chosen network tier, verify the routing actually works for your audience in the first 72 hours, and only then upgrade.
